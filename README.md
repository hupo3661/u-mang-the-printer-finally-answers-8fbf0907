Entry for the make.fun competition
[u-mang-the-printer-finally-answers-8fbf0907](https://make.fun/c/u-mang-the-printer-finally-answers-8fbf0907):
one line, 1 to 240 characters, as the office printer's comeback
to the jams, the error codes and the thumps.

## The line

> I have printed 40,000 pages without a single thank-you, and the one time I jam, you hit me like I did it on purpose.

(116 characters, one sentence. Also saved in `entry.txt`.)

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` and prints it. The program
checks the line is non-empty, a single sentence, and at most 240
characters, then reads the file back to verify it matches.
